# Security Policy

## Supported versions

The latest released NuGet package receives security updates. Older versions are
not maintained; update regularly.

## Reporting a vulnerability

Please report security issues **privately** via GitHub's
[private vulnerability reporting](https://github.com/st0o0/ProjectName/security/advisories/new)
(Security → Advisories → *Report a vulnerability*). Do **not** open a public
issue for security problems.

You can expect an initial response within a few days. Once a fix is available it
is released and the advisory is published.

## Scope

Dependencies are scanned weekly with Trivy and results appear in the
repository's Security tab.
